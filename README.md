The one line a smart fridge texts its owner at 3am — an appliance that has
been awake all night, watching its owner open it just to stare at nothing,
finally deciding this is the moment to speak.

Built for [make.fun](https://make.fun/c/u-deysumbrella-the-3am-fridge-text-4c3e721d?ref=jme44qjv) — bounty: [The 3AM Fridge Text](https://make.fun/c/u-deysumbrella-the-3am-fridge-text-4c3e721d).

## How it works

`main.py` (pure Python 3 stdlib) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` with no trailing newline.

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
